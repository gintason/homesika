# ADR-0005: Phone OTP plus a 6-digit login PIN on trusted devices

**Status:** proposed · **Date:** 2026-10-15

**Decision:** reuse Goldia's tested flow:
* sign-up with phone and email, verified by a one-time code (SMS, with email fallback);
* create a 6-digit login PIN;
* PIN-only login on the bound device;
* a new device needs PIN plus OTP;
* a PIN reset signs out every other device;
* a separate 4-digit transaction PIN for money actions.

The PIN is checked on the server, with a lockout after 5 wrong attempts.

**Open:** web dashboard staff sign-in, either the same OTP plus PIN, or email and password plus
OTP as a second factor. Recommended: the same identity, with OTP on each new browser.
